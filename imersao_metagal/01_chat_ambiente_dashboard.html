FUNDAMENTO // O CHAT

O chat não é um buscador

Buscador responde com links. Chat responde fazendo junto com você: escreve, organiza, calcula, monta tela, corrige e itera.

BuscadorVocê pergunta → recebe páginas → lê → monta sozinho. A resposta é um caminho, não o resultado.
Chat com IAVocê descreve o que precisa → a IA constrói → você ajusta → sai com o entregável pronto.

IA BUILDER · METAGAL07
PEÇA 01 // VS CODE

VS Code — onde a solução nasce

É a “oficina”. Arquivos da solução, pastas, chat com IA, terminal — tudo no mesmo lugar. É onde você constrói e organiza.

  • Você vê a estrutura do projeto como pastas e arquivos, não como “caixa preta”.
  • É o lugar onde a IA edita o código junto com você.
  • Analogia: o VS Code é a mesa de trabalho; o chat é o colega ao lado.
OFICINAORGANIZAÇÃOCONSTRUÇÃO
IA BUILDER · METAGAL08
PEÇA 02 // GITHUB

GitHub — histórico e versões

É o “cofre com linha do tempo”. Guarda o projeto na nuvem e registra cada versão — o que mudou, quando e por quê.

  • Se algo quebrar, você volta para uma versão anterior.
  • O time trabalha no mesmo projeto sem sobrescrever o arquivo um do outro.
  • Analogia: não é “salvar como v2_final_FINAL.xlsx” — é histórico automático e organizado.

PEÇA 03 // BANCO DE DADOS

Banco — dado organizado

Não é arquivo solto na pasta. É informação estruturada em tabelas, pronta para consultar, filtrar e conectar com a solução.

Arquivo soltoPlanilha na mesa, PDF no e-mail, CSV na pasta Downloads. Difícil de manter, fácil de perder.
Banco estruturadoTabelas (fornecedores, pedidos, itens). A solução lê e grava de forma confiável.

CONEXÃO // O PORQUÊ

Como as 3 peças se conectam

Primeiro o porquê. O como (contas, instalação, cliques) vem depois — quando fizer sentido no projeto.

  • VS Code cria e altera a solução (a lógica, as telas, os arquivos).
  • GitHub guarda cada versão segura desse trabalho — histórico e backup.
  • Banco alimenta a solução com dados vivos (pedidos, fornecedores, status).
  • Sem mapa: parece “muita ferramenta”. Com mapa: é um sistema com 3 papéis claros.

IA BUILDER · METAGAL16
PROJETO 01 // PASSO A PASSO

Como o projeto acontece

  • 1. Traga um arquivo real de Compras (export, controle, ranking).
  • 2. Digá à IA o que quer ver: KPIs, gráficos, filtros, ranking.
  • 3. Ela gera o dashboard em HTML + CSS + JS.
  • 4. Você abre no navegador — sem banco, sem publicar nada.
  • 5. Ajusta: “tire essa coluna”, “adicione atraso médio”, “destaque o top 5”.
