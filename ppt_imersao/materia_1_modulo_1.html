FUNDAMENTO // CONCEITO

O que é Vibe Coding?

Termo cunhado por Andrej Karpathy em 2025. É programar conversando com a IA em linguagem natural, deixando a máquina escrever o código enquanto você guia, testa e ajusta. Você foca no quê e no porquê; a IA cuida do como.

  • Linguagem natural substitui boa parte da sintaxe técnica.
  • Foco em intenção e resultado, não em decorar comandos.
  • O dev (ou criador) vira diretor do projeto, não digitador.

REALIDADE // DESAFIOS

Desafios para quem não é programador

Vibe coding não é mágica. A IA acelera muito, mas existem armadilhas que travam quem está começando. Conhecer cedo evita frustração.

  • Vocabulário técnico: termos como deploy, repo, branch, env podem assustar no começo.
  • Alucinação da IA: ela inventa funções e bibliotecas. Você precisa testar e questionar.
  • Debug de erro: quando algo quebra, é preciso aprender a ler logs e perguntar bem.
  • Segurança: chaves de API expostas, dados sensíveis e permissões podem virar problema sério.
  • Manutenção: código gerado precisa ser organizado, senão vira bola de neve em 2 semanas.

FUNDAMENTO // O QUE É IDE

O que é uma IDE?

Integrated Development Environment, ambiente de desenvolvimento integrado. É o programa onde você escreve, testa e publica código em uma só janela, com tudo conectado.

  • Editor de código com destaque de sintaxe, autocomplete e atalhos.
  • Terminal integrado para rodar comandos sem sair da IDE.
  • Controle de versão com Git e GitHub plugados nativamente.
  • Debug e extensões para qualquer linguagem ou framework.

COMPARATIVO // ABORDAGENS

IDE com IA vs Ferramentas de IA

IDEs com IA• Você tem o código na sua máquina
• Controle total: arquivos, Git, deploy
• Curva inicial maior
• Escala bem para projetos sérios e longos
• Exemplos: Cursor, Windsurf, VS Code
Ferramentas de IA• Tudo no navegador, sem instalar nada
• App pronto e online em minutos
• Curva quase zero
• Limites de customização e exportação
• Exemplos: Lovable, v0, Bolt.new

Resumo: ferramentas web são ótimas para começar e prototipar. IDEs com IA são o ambiente para crescer e manter o projeto.

FLUXO // COMBO IDEAL

A combinação dos dois mundos

O fluxo mais poderoso é começar na ferramenta de IA e depois continuar na IDE com IA. Você ganha velocidade no início e controle no longo prazo.

  • 1. Prototipe rápido no Lovable, v0 ou Bolt.new para validar a ideia visualmente.
  • 2. Exporte ou conecte ao GitHub o código gerado pela ferramenta.
  • 3. Abra no Windsurf, Cursor ou Antigravity e evolua o projeto com a IDE com IA.
  • 4. Mantenha versionado no GitHub e faça deploy quando quiser.
